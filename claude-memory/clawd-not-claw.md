Parody names pun on **Clawd**, never on "claw", even when the character really has claws. Example: Stranger Clawds' Demogorgon is the **Democlawdgon**, not the Democlawgon.

**Why:** on 2026-10-22 the owner said: "stop using "claw" unless its actually because of the claws on the character.. for example it should be "democlawdgon"", then added "even though it has claws".

**How to apply:** check every new pun name for a bare "claw". Released universes still have about twenty (Buffy Clawmers, Draclawla, Ian Malclawm, Captain Clawk, Glorificlaws…); renaming those is the owner's call, so ask first. Related: [[stranger-clawds]], [[superclawdtural]].
