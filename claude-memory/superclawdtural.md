The Supernatural (TV show) universe being added to Clawd Clash is called **Superclawdtural**, spelled with "clawd" (the brand), not "claw". The user corrected "Superclawtural" to this on 2026-10-17.

**Why:** every universe name carries "Clawd" as the brand word (Star Clawds, Doctor Clawd, The Clawd Files, Stevie Clawdberg, Clawd of the Rings), so the pun keeps the full "clawd" even when it sits mid-word.

**How to apply:** use "Superclawdtural" in titles, README, captions and the promo; a code key like `supernatural` is fine (keys use the franchise, as `starWars` does). Related: [[stevie-clawdberg]], [[clawd-clash-plan]], [[no-em-dashes]].
